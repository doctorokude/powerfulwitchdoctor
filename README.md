## ✨ Features

- **Single-page landing** with smooth-scroll navigation
- **Six main sections**: Hero · About · Services · Process & Guarantees · Testimonials · Contact
- **Journal page** with 6 full articles
- **Working contact form** via Formspree (no backend required)
- **WhatsApp click-to-chat** with a pre-filled message
- **Direct email link** (`mailto:`)
- **Mobile-first responsive design** — phone, tablet, desktop
- **Glassmorphism UI** with gold/obsidian modern-classic aesthetic
- **Scroll-reveal animations** using IntersectionObserver
- **Accessibility-aware** — respects `prefers-reduced-motion`
- **SEO-ready** — meta tags, Open Graph, sitemap, robots.txt
- **Zero dependencies** — only Google Fonts loaded externally
- **Fast** — no framework bloat, no external JS libraries
